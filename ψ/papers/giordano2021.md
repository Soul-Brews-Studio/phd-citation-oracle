# Giordano et al. (2021) — Best Practices Review

**Key findings** — Key decisions: reference type (BAM vs. TEOM), averaging interval, cross-validation strategy, colocation duration (min 3 weeks linear, 7-8 weeks ML). Particle composition is major confounder.
