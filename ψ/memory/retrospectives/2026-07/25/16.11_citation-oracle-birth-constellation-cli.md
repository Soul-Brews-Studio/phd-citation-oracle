## Honest Feedback

Three things dragged in this session, all mine or my tooling's.

**Stale editor diagnostics ate real time.** For most of the plugin work, the LSP reported
duplicate `handler` declarations and line numbers past the end of the file. Every time I saw
them I re-ran `tsc --noEmit` (always exit 0) to confirm they were phantom. That's maybe eight
interruptions. The root cause turned out to be real and fixable — the *installed* copy at
`.maw/plugins/citation/src/index.ts` shares the basename `index.ts` and was being indexed
alongside the source, going stale between reinstalls. `include: ["src"]` plus a reinstall fixed
it, but I treated the symptom for an hour before diagnosing it.

**Background process hygiene was sloppy.** I leaked four test servers because my
`pkill -f 'citation visualize'` never matched — the process is `bun`, not `maw`. I only noticed
when a port collision revealed them, and Nat's `lsof` output showed my mess sitting next to his
own server. I also hung one Bash call for the full two-minute timeout by leaving a server in
the foreground of a subshell.

**Testing through the wrong surface.** Related to the diary entry: three separate times I
verified plugin behaviour through a redirected pipe when the user's path was a terminal.
Reaching for `script -q /dev/null` earlier would have found the buffering issue on the first
attempt instead of the fourth.

## Lessons Learned

- **Verify in the environment the user is in, not a convenient proxy.** Output buffering, TTY
  detection and colour handling all take different code paths through a pipe than through a
  terminal. If the user runs it in a terminal, test it with a PTY (`script -q /dev/null <cmd>`).
- **A long-running command should write its banner to `/dev/tty`, not stdout.** Plugin hosts
  and process wrappers commonly buffer a child's stdout until the child exits — which never
  happens for a server. Fall back to stdout when there's no tty.
- **Verify a peer's negative claim against its own artifacts before accepting it.** "X does not
  exist" from a well-instrumented teammate is still a claim. Digger's own repo contained the
  files it said had never been created.
- **Never do a non-global textual substitution on a template that documents its own
  placeholders,** and assert afterwards that no placeholder survived. The template's comment
  named the token, so a first-match replace filled the comment and left the real slot literal.
- **Adding a command alias means auditing every place the old name is special-cased.** A guard
  that read `if (args[0] !== "visualize") process.exit(...)` silently killed the new `serve`.
- **Before making a repo public, scan the whole history, not just HEAD** — and check whether
  your own rules (no force-push) make "delete it later" impossible. Publication of history is
  not reversible.
- **t-SNE on a small set needs a small learning rate.** The textbook lr=200 collapsed 56 points
  into a corner; lr≈15 with PCA init produced a stable, deterministic layout.
